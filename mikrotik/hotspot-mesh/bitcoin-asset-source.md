# Bitcoin mark

`bitcoin.svg` is the downloaded standard Bitcoin mark, served locally so the
welcome page does not need Internet access to display it.

- File: https://upload.wikimedia.org/wikipedia/commons/4/46/Bitcoin.svg
- Source and public-domain record: https://commons.wikimedia.org/wiki/File:Bitcoin.svg
- Retrieved: 6 October 2026.

The Mesh mark and Geist typeface remain unchanged. This asset is not a newly
drawn symbol or a font glyph.
